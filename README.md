# 🤖 AI Voice Assistant Telegram Bot

Асинхронный Telegram-бот, который превращает голосовые сообщения в текст и делает из них краткую выжимку (Summary) с помощью нейросети. Создан для экономии времени при прослушивании длинных аудиосообщений.

## 🚀 Возможности (Features)
- **Распознавание голоса (Speech-to-Text):** Автоматическое скачивание голосовых сообщений из Telegram (.ogg) и перевод их в текст.
- **ИИ-Суммаризация:** Выделение главной сути из текста с помощью LLM (GigaChat API).
- **База данных:** Сохранение уникальных пользователей в локальную БД для ведения статистики.
- **Асинхронность:** Бот написан на современном фреймворке Aiogram 3, работает быстро и не блокируется при долгих запросах к API.
- **Индикация статуса:** Пользователь видит процесс работы бота (Скачивание -> Распознавание -> Генерация ответа).

## 🛠 Стек технологий
- **Язык:** Python 3.14.2
- **Фреймворк:** Aiogram 3.26
- **База данных:** SQLite (библиотека `aiosqlite` для асинхронных запросов)
- **API ИИ:** GigaChat API (Сбер)
- **Работа с аудио:** `SpeechRecognition`, `pydub`
- **Системные зависимости:** FFmpeg (для конвертации .ogg в .wav)
